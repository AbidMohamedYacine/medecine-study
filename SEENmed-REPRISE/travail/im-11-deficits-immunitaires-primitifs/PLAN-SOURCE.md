## Ancres fidélité (source fait foi — audio = zéro écart)
- >200 types ; prévalence ~1/10 000 ; forte consanguinité ; varie selon la région.
- Cellulaire : germes intracellulaires (mycobactéries, candida, *Pneumocystis carinii*) dès les premiers mois. Humoral : pyogènes extracellulaires (Haemophilus, pneumocoques), ORL/poumon, après 6 mois. Phagocytose : « sans pus »/granulomatose peau-poumon-os (staphylocoque, candida, aspergillus). Complément : surtout *Neisseria*.
- 9 catégories (ordre d10) : cellulaire+humorale ; prédominance humorale ; phagocytaires congénitaux ; complément ; dysrégulation immune ; syndromiques ; immunité innée ; auto-inflammatoires ; phénocopies.
- DIC : retard de croissance++ ; vaccins vivants atténués ! ; sang total proscrit (GVH) → déleucocyté/irradié ; lymphopénie surtout LT ; pas de réponse stimulations in vitro.
- SCID : T-B-NK+ (RAG1/2, ARTEMIS, DNA PKC) ; T-B+NK- (lié à l'X++, Jak3, CD45) ; T-B+NK+ (chaîne α IL-7R, CD3 δεζ) ; T-B-NK- (ADA, dysgénésie réticulaire) ; point commun : absence de LT. — Ne RIEN ajouter (pas de γc/IL2RG : absent du cours).
- HLA-II : bassin méditerranéen+++ ; AR ; régulation transcriptionnelle ; LT normal mais lymphopénie CD4 → inversion CD4/CD8.
- Humoraux : Bruton (lié au sexe) ; déficit IgA = le plus fréquent de tous les DIP ; CVID ; sous-classes IgG ; chaîne kappa ; transcobalamine II ; déficit sélectif en Ac Ig normales ; hypogamma transitoire.
- Complément : classique >> MAI+infections ; alterne >> pyogènes/*Neisseria* ; lectines >> *Neisseria* ; commune >> méningite ; régulation >> consommation ; C1inh >> angio-œdème héréditaire.
- Phagocytes : neutropénie congénitale (nombre) ; mobilité (fonction) ; granules PNN (fonction). TLR ~15 membres, PAMPs. Axe IL-12/IFNγ → mycobactéries.
- Orientation (d29) : sans pus/gingivites/fistules périanales/omphalite → LAD ; ataxie+télangiectasie → AT ; hypoplasie thymique+malformations cardiaque/faciale → Di George ; abcès/granulomes/pyodermite → granulomatose septique chronique ; thrombopénie+eczéma → Wiskott-Aldrich.
- Exploration : É1 interrogatoire/examen (âge début, fratrie, consanguinité, décès, BCGite) ; É2 HIV à éliminer, FNS (hyperleucocytose→LAD ; lymphopénie nourrisson→SCID ; thrombopénie→WAS), EPS, Ig G/A/M, sérologies vaccinales, CH50 ; É3 phénotypage LT/LB/NK, TTL (PHA), sous-classes IgG, fractions complément, NBT, ADA, cytokines, cytotoxicité ; É4 génétique/séquençage++.
- Traitement : symptomatique (perfusion Ig, antibiothérapie), greffe de moelle osseuse, thérapie génique.
